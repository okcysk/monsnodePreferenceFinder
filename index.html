    ショートカット

    再生操作はフォーカス中のセル（緑の枠・番号が緑）に効きます。フォーカスは W/A/S/D・Tab・クリックで移動します。

    順位付け
    1〜4
    そのセルに次の順位を付ける / 外す
    Enter
    送信
    Backspace
    1つ戻す
    Q
    フォーカス中の動画を評価しない / 戻す（再生されない時など。以後は出てこない）
    全体
    Shift+再生キー
    右の再生操作をすべて4本まとめて実行（例 Shift+Space 全部 再生/停止、Shift+X 全部 5秒進む、Shift+G 全部 2.5x）
    フォーカス
    WASD
    上 / 左 / 下 / 右のセルへ
    Tab
    次のセルへ（Shift+Tab で前へ）
    再生（フォーカス中のセル）
    Space
    再生 / 一時停止
    Z / X
    5秒 戻る / 進む
    C / V
    30秒 戻る / 進む
    F
    速度を 1.0x に戻す
    G / H
    2.5x / 10x 切替
    M
    ミュート / 解除
    ↑ / ↓
    音量 上げる / 下げる
